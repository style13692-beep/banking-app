Platform features

Everything you need,
nothing you don't.

A fully functional banking platform built with Node.js, Express, and Azure SQL — deployed on a Windows Server VM and secured with Azure Key Vault, Managed Identity, and Entra ID.

🏦
Live dashboard
See your balance, recent transactions, and account status at a glance — powered by the Node.js API and Azure SQL Database, updated in real time each session.
🔐
JWT security
Sessions are secured with a 64-character signing key stored in Azure Key Vault — signed and verified on every API request, with a configurable 24-hour token lifetime.
☁️
Azure Key Vault
All 8 application secrets — SQL connection string, JWT signing key, Entra ID credentials, CORS origins — are stored in Key Vault and never hardcoded in source code.
👥
RBAC roles
Two roles — Customer and Admin — are defined in Azure Entra ID App Roles. Admins can view all users via a protected endpoint; customers see only their own data.
📊
Transaction history
A full ledger of credits and debits stored in Azure SQL Database, with timestamps, descriptions, and running balance — displayed clearly on your personal dashboard.
🆔
Managed identity
The Windows Server VM uses a System-Assigned Managed Identity to authenticate with Azure Key Vault — no passwords or credentials are stored anywhere in code or config files.
